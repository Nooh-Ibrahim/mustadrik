# مُستدرِك — نسخة سطح المكتب (Electron)

تطبيق ويندوز مستقل لإدارة الدراسة: بومودورو، مهام، عادات، صلوات، أهداف، وإحصائيات — يعمل بالكامل دون إنترنت (عدا جلب مواقيت الصلاة الاختياري).

## التشغيل السريع (للمطور)

```powershell
npm install          # تثبيت Electron + electron-builder
npm run prep         # توليد الأيقونة + تنزيل الخطوط وأيقونات lucide للعمل أوفلاين
npm start            # تشغيل التطبيق في وضع التطوير
npm run dist         # بناء ملفات .exe في مجلد dist
```

## المخرجات (مجلد `dist`)

| الملف | الوصف |
|---|---|
| `NoahDashboard-Portable-10.0.0.exe` | **نسخة مستقلة** تعمل بنقرة دون تثبيت |
| `NoahDashboard-Setup-10.0.0.exe` | مُثبِّت مع اختصارات سطح المكتب وقائمة ابدأ |

## البنية

```
main.js            عملية Electron الرئيسية (نافذة، قائمة، IPC، نسخ احتياطي على القرص)
preload.js         جسر آمن (contextIsolation) يكشف window.noahAPI فقط
src/index.html     الواجهة
src/styles.css     الأنماط
src/js/            منطق التطبيق — 10 وحدات (core, storage, shell, timer, tasks, habits, stats, prayer, home, bootstrap)
src/assets/        خطوط Tajawal + lucide (مضمّنة للعمل أوفلاين)
scripts/           أدوات: توليد الأيقونة، تنزيل الأصول، التقسيم، اختبار الدخان
build/icon.ico     أيقونة التطبيق
```

## أهم ميزات الإصدار العاشر (v10)

- **دقة المؤقت:** يعتمد على الطابع الزمني الفعلي (لا ينحرف في الخلفية).
- **إشعارات سطح المكتب** + وميض شريط المهام والعنوان عند انتهاء الجلسة.
- **أمان البيانات:** نسخة مرآة في المتصفح + نسخة يومية تلقائية على القرص (`%AppData%/Noah Dashboard/backups`) + استرجاع تلقائي عند التلف + ترقية البنية (schema migration).
- **اختصارات لوحة المفاتيح:** مسافة (تشغيل/إيقاف)، F (تركيز)، N (مهمة)، 1–9 (تنقّل)، Esc.
- **عمل كامل دون إنترنت** (خطوط وأيقونات مضمّنة، CSP مُقيّد).
- **تحليلات ذكية:** متوسط الجلسة، أنشط وقت، اتجاه أسبوعي، أيام الدراسة.
- **بحث في المهام** + **ترتيب يدوي بالسحب والإفلات**.
- **تأكيد قبل الحذف** عبر نافذة أنيقة.

## النسخ الاحتياطي

- تلقائياً: نسخة واحدة يومياً (يُحتفظ بآخر 14) في مجلد بيانات التطبيق.
- يدوياً: الإعدادات ← البيانات ← «انسخ الآن» / «استعادة» / «المجلد».
- التصدير/الاستيراد بصيغة JSON متاح أيضاً.
